# Atualizações da versão 5

- Chave da Google Maps Embed API inserida em `js/config.js`.
- Prévia do mapa da propriedade ativada quando latitude e longitude forem informadas.
- URL do Firebase preservada para sincronização entre aparelhos.

## Segurança

Como o site é publicado no GitHub Pages, a chave aparece no JavaScript do navegador. Restrinja a chave no Google Cloud Console para uso exclusivo da Maps Embed API e, de preferência, limite o uso ao domínio do projeto.
